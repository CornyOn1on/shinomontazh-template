# Реальные фотографии компании

Положите сюда настоящие фотографии шиномонтажа. Эти файлы приоритетнее заглушек.

## Как подключить

1. Скопируйте файлы в эту папку, например:

   ```
   public/images/company/zona-1.jpg
   public/images/company/balansirovka.jpg
   public/images/company/podezd.jpg
   ```

2. Откройте панель управления (Pages CMS), раздел **Фотографии**,
   и укажите в поле «Путь к изображению»:

   ```
   /images/company/zona-1.jpg
   ```

3. Снимите галочку **«Это изображение-заглушка»**.
4. Сохраните изменения. GitHub Actions пересоберёт сайт автоматически.

## Требования к файлам

- Форматы: JPG, PNG, WebP, SVG.
- Рекомендуемый размер: 1600×1200 (соотношение 4:3) или 1920×1080.
- Вес одного файла: до 500 КБ (сжимайте перед загрузкой).
- Обязательно заполняйте **alt-текст** — он нужен для доступности и SEO.

## Важно

Файлы из `public/images/placeholders/` — это нейтральные заглушки шаблона.
Они не являются фотографиями конкретной компании и должны быть заменены
перед передачей сайта клиенту.
