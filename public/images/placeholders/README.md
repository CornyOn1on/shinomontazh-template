# Заглушки шаблона

Эти изображения — нейтральные заглушки, которые поставляются вместе с шаблоном.
Они **не являются фотографиями какой-либо конкретной компании**.

Каждая заглушка помечена в `content/gallery.json` флагом `"isPlaceholder": true`,
поэтому на сайте отображается бейдж «Заглушка» и пояснительная подпись.

## Как заменить на реальные фотографии

1. Положите настоящие фото в `public/images/company/`.
2. В Pages CMS откройте раздел **Фотографии**.
3. Для каждой записи измените «Путь к изображению» на `/images/company/имя-файла.jpg`.
4. Снимите галочку **«Это изображение-заглушка»**.
5. Сохраните — сайт пересоберётся автоматически.

Файлы заглушек можно оставить в репозитории: пока на них нет ссылок в
`content/gallery.json`, они не попадают на страницу.
