# Брендинг

Папка для постоянных файлов оформления: логотип, изображение для Open Graph
(превью при отправке ссылки в мессенджерах), иконка сайта.

## Логотип

Положите файл сюда, например `public/branding/logo.png`, и укажите путь
в настройках компании (Pages CMS → **Общие настройки** → «Логотип»):

```
/branding/logo.png
```

Логотип необязателен. Если он не указан, сайт показывает название компании
текстом — без битой картинки и без пустого места.

Требования к логотипу:

- Форматы: PNG с прозрачностью, SVG или WebP.
- Высота: 80–120 px (сайт сам подгоняет размер).
- Горизонтальное расположение предпочтительнее.
- Пропорции сохраняются автоматически, изображение не растягивается.

## Превью для мессенджеров (og:image)

Файл `public/branding/og-image.jpg`, размер 1200×630.
Указывается в Pages CMS → **Общие настройки** → «Изображение Open Graph».
