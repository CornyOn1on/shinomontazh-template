# Файлы, загруженные через панель управления

Сюда Pages CMS складывает изображения, которые владелец загружает напрямую
через интерфейс (например, логотип или новые фотографии галереи).

Путь к загруженному файлу в контенте выглядит так:

```
/uploads/logo.png
/uploads/foto-1.jpg
```

Ничего удалять из этой папки вручную не нужно: если файл перестал быть нужен,
сначала уберите ссылку на него из соответствующего JSON-файла в `content/`.
