# Массовое создание сайтов из шаблона

Инструкция для того, кто делает много сайтов шиномонтажей на одном шаблоне.

---

## Как устроено

```
tire-service-shchekino/     ← ШАБЛОН (эталон). Правки кода делаются здесь.
site-01/                    ← сайт компании 1 (свой репозиторий, свой домен)
site-02/                    ← сайт компании 2
...
site-15/                    ← сайт компании 15
```

Каждый сайт — это **точная копия шаблона** с данными одной компании.
Код во всех папках одинаковый. Различаются только:

- `content/site.json` — компания, контакты, координаты, SEO
- `content/services.json` — услуги и цены
- `content/gallery.json` — фотографии
- `content/reviews.json` — отзывы
- `public/images/company/` — файлы фотографий

> **Важно:** правки кода (React-компоненты, стили, `.pages.yml`) нужно
> делать в шаблоне, а потом раскатывать в папки. Иначе они разойдутся,
> и поддерживать 15 разных версий станет невозможно.

---

## Инструменты

В каждой папке есть `tools/`:

| Файл | Что делает |
| --- | --- |
| `tools/clone-template.mjs` | Создаёт N копий шаблона |
| `tools/apply-companies.mjs` | Заливает данные из таблицы во все папки |

---

## Шаг 1. Создать копии

Из папки шаблона:

```bash
cd tire-service-shchekino

# 15 копий с префиксом site- (site-01 ... site-15)
node tools/clone-template.mjs 15

# другой префикс
node tools/clone-template.mjs 15 --prefix shinomontazh-

# продолжить нумерацию с 16-й
node tools/clone-template.mjs 5 --from 16
```

Скрипт не трогает уже существующие папки — повторный запуск безопасен.

---

## Шаг 2. Заполнить таблицу

Возьмите образец `data/companies.example.csv` и заполните в Excel или
Google Sheets. **Одна строка = одна компания.**

### Обязательные колонки

| Колонка | Что писать | Пример |
| --- | --- | --- |
| `site` | Папка сайта | `site-01` |
| `название` | Название компании | `Шиномонтаж на Советской` |
| `город` | Город | `Щёкино` |
| `адрес` | Адрес | `ул. Советская, 2а/3` |
| `телефон` | Телефон | `+7 (950) 928-20-99` |
| `телеграм` | Telegram без @ | `Maksim71ru` |
| `карты` | Ссылка на Яндекс Карты | `https://yandex.ru/profile/...` |

### Полезные колонки

| Колонка | Формат | Пример |
| --- | --- | --- |
| `широта` / `долгота` | Число с точкой | `54.01445` / `37.51334` |
| `рейтинг` | Число | `4.3` |
| `отзывов` | Число | `5` |
| `режим` | Текст | `Каждый день с 9:00 до 19:00` |
| `услуги` | `Название=Цена` через `;` | `Шиномонтаж=500;Балансировка=400` |
| `единица` | Текст | `за колесо` / `за комплект` |
| `фото` | Имена файлов через `;` | `foto-1.jpg;foto-2.jpg` |
| `преимущества` | Пункты через `;` | `Работаем без выходных;Своя парковка` |
| `отзывы` | `Имя\|Дата\|Текст` через `;` | `Иван П.\|13.09.2026\|Всё быстро` |
| `max` | `true` / `false` | `false` |
| `seo-заголовок` | Текст | `Шиномонтаж в Щёкино` |

### Форматы, которые понимает скрипт

**Дата в отзывах** — любой из вариантов:

- `13.09.2026`
- `2026-09-13`
- `13 сентября`
- `13.09` (год подставится текущий)

**Цена** — можно писать как угодно:

- `Шиномонтаж=500`
- `Балансировка=400`
- `Ремонт прокола=по запросу` (если не число — станет «по запросу»)

> **Осторожно с Excel:** программа может превратить `+7 (950)...` в формулу.
> Форматируйте колонку телефона как **текст** заранее.

---

## Шаг 3. Сохранить таблицу

**Вариант А — CSV:** «Файл → Сохранить как → CSV (разделитель — запятая)».
Кириллица должна быть в UTF-8.

**Вариант Б — TSV из Excel:** выделить всё, скопировать, вставить в текстовый
файл `data/companies.tsv`. Скрипт сам определит разделитель.

Положите файл в `data/` любого сайта (или в шаблон).

---

## Шаг 4. Применить данные

Из папки шаблона:

```bash
# Сначала посмотреть, что будет сделано — ничего не записывается
node tools/apply-companies.mjs data/companies.csv --dry-run

# Записать во все сайты
node tools/apply-companies.mjs data/companies.csv

# Только в конкретные сайты
node tools/apply-companies.mjs data/companies.csv --site site-01,site-02
```

Скрипт сам разложит данные по четырём JSON-файлам в каждой папке и
переключит `displayMode`:

- есть фотографии → `photos` (обычный вид);
- нет фотографий → `no-photos` (дизайн-блоки вместо снимков).

## Шаг 5. Добавить фотографии

Для каждой компании скопируйте фото в свою папку:

```
site-01/public/images/company/foto-1.jpg
site-02/public/images/company/foto-1.jpg
```

Имена файлов должны совпадать с колонкой `фото` в таблице.

### Подготовка фотографий

Фото с телефона весят 3–5 МБ каждое — это слишком много. Приведите их к
веб-размеру: **1600×1200, 4:3, до 400 КБ, JPEG**.

Скрипт для пакетной обработки (нужен `npm install sharp`):

```js
// tools/process-photos.mjs — положите рядом с другими инструментами
import sharp from "sharp";
import { promises as fs } from "node:fs";
import path from "node:path";

const inputDir = process.argv[2];   // откуда брать
const outputDir = process.argv[3];  // куда класть

const files = await fs.readdir(inputDir);
for (const file of files) {
  if (!/\.(jpe?g|png|webp)$/i.test(file)) continue;

  await sharp(path.join(inputDir, file))
    .rotate()                                   // учесть ориентацию из EXIF
    .resize(1600, 1200, { fit: "cover", position: "centre" })
    .jpeg({ quality: 82, progressive: true, mozjpeg: true })
    .withMetadata({ orientation: undefined })    // убрать EXIF и геометку
    .toFile(path.join(outputDir, file));

  console.log(file, "готово");
}
```

Запуск:

```bash
node tools/process-photos.mjs "C:/фото/шиномонтаж-1" site-01/public/images/company
```

## Шаг 6. Проверить каждый сайт

```bash
cd site-01
npm install
npm run typecheck   # без ошибок
npm run build       # собирается
npm run dev         # откройте http://localhost:5173
```

Проверьте вручную:

- [ ] название, адрес и телефон верные
- [ ] фотографии загружаются
- [ ] «Построить маршрут» ведёт на нужный адрес
- [ ] Telegram открывает чат с текстом заявки
- [ ] отзывы на месте
- [ ] нет горизонтальной прокрутки на телефоне

## Шаг 7. Опубликовать

Для каждого сайта — **отдельный репозиторий**:

```bash
cd site-01
git init
git add .
git commit -m "Сайт: Шиномонтаж на Советской"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/shinomontazh-1.git
git push -u origin main
```

Затем:

1. **Settings → Pages → Source: GitHub Actions.**
2. Домен: скопировать `CNAME.example` в `public/CNAME`, вписать домен,
   настроить DNS, включить Enforce HTTPS.
3. **Pages CMS:** установить GitHub App на репозиторий,
   пригласить владельца по email.

## Что делать, если нужно поменять код во всех сайтах

1. Внести правку в шаблон `tire-service-shchekino/`.
2. Проверить: `npm run typecheck && npm run build`.
3. Перенести изменения в папки. Только код, **не данные**:

```bash
# Пример: обновить компоненты и стили во всех сайтах
foreach ($d in 1..15) {
  $p = "site-{0:D2}" -f $d
  Copy-Item "tire-service-shchekino\src\*" "$p\src\" -Recurse -Force
  Copy-Item "tire-service-shchekino\.pages.yml" "$p\.pages.yml" -Force
}
```

Затем закоммитить и запушить в каждый репозиторий.
GitHub Actions пересоберёт сайты автоматически.

## Частые ошибки

| Проблема | Причина | Решение |
| --- | --- | --- |
| Телефон превратился в число | Excel воспринял `+7...` как формулу | Формат колонки — «Текст» |
| Кириллица стала «крякозябрами» | CSV сохранён не в UTF-8 | Сохранить как CSV UTF-8 |
| Услуги одной строкой | Разделитель — не `;` | Внутри ячеек только `;` |
| Фото не найдены | Не совпадают имена файлов | Имя в таблице = имя файла |
| Скрипт пишет «папка не найдена» | Неверная колонка `site` | Проверить имена папок |
| Данные затёрли друг друга | Два раза указана одна папка | Уникальный `site` на строку |
