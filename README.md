# Сайт шиномонтажа — шаблон для Щёкино (Тульская область)

Готовый одностраничный сайт для местного шиномонтажа. Работает полностью
без сервера и базы данных, размещается на GitHub Pages, а контент владелец
меняет сам через бесплатную панель Pages CMS.

Один шаблон — много компаний: для каждого шиномонтажа создаётся отдельный
GitHub-репозиторий со своим доменом и своим набором данных. Код править
не нужно — меняются только данные и фотографии.

## 1. Что умеет сайт

- Показывает услуги и цены.
- Показывает фотографии работ и площадки в галерее с увеличением по клику.
- Показывает отзывы и средний рейтинг со ссылками на Яндекс Карты.
- Даёт контакты: адрес, телефон, режим работы, мессенджеры.
- Строит маршрут до конкретного адреса в Яндекс Картах.
- Готовит текст заявки и открывает чат с владельцем в Telegram.
- Поддерживает второй мессенджер MAX.
- Умеет скопировать заявку в буфер обмена — для любого другого мессенджера.
- Работает без сервера: после сборки это обычные статические файлы.

Сайт **не** отправляет заявки автоматически. Об этом честно написано и в
интерфейсе, и в разделе [10](#10-как-работает-форма-заявки).

## 2. Из чего состоит проект

| Технология | Зачем |
| --- | --- |
| React + TypeScript | Разметка и логика интерфейса |
| Vite | Быстрая разработка и сборка в папку `dist` |
| CSS (без библиотек) | Свой дизайн, светлая тема, поддержка `prefers-reduced-motion` |
| GitHub Pages | Бесплатный хостинг статики |
| GitHub Actions | Автоматическая сборка после изменения контента |
| Pages CMS | Панель управления контентом прямо в репозитории |
| JSON-файлы | Единственный источник текстов, цен и контактов |

Чего в проекте нет и не будет: Supabase, баз данных, Telegram-бота, Bot API,
серверной отправки форм, обязательного VPS, платного backend, токенов в
клиентском коде, `mailto:` как основного способа связи.

## 4. Локальный запуск

Нужен Node.js 20 или новее.

```bash
# 1. Установить зависимости
npm install

# 2. Запустить сайт для разработки
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://localhost:5173).

Остальные команды:

```bash
npm run typecheck   # Проверка TypeScript без сборки
npm run build       # Production-сборка в папку dist
npm run preview     # Локальный просмотр собранной версии
npm run clean       # Удалить папку dist
```

Перед публикацией всегда полезно выполнить:

```bash
npm run typecheck && npm run build
```

Если обе команды прошли без ошибок — сайт соберётся и на GitHub.

## 5. Публикация на GitHub Pages

### Шаг 1. Создайте репозиторий

```bash
git init
git add .
git commit -m "Первый коммит: сайт шиномонтажа"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/ВАШ-РЕПОЗИТОРИЙ.git
git push -u origin main
```

### Шаг 2. Включите GitHub Pages

1. Откройте репозиторий на GitHub.
2. **Settings** → **Pages**.
3. В разделе **Build and deployment** → **Source** выберите **GitHub Actions**.

### Шаг 3. Дождитесь сборки

Откройте вкладку **Actions**. Сценарий «Deploy site to GitHub Pages» выполнит:

1. установку зависимостей;
2. проверку TypeScript;
3. определение базового пути;
4. production-сборку в `dist`;
5. загрузку `dist` как Pages Artifact;
6. публикацию сайта.

Через 1–3 минуты сайт будет доступен по адресу:

```
https://ВАШ-ЛОГИН.github.io/ВАШ-РЕПОЗИТОРИЙ/
```

> **Про базовый путь.** Если файла `public/CNAME` нет, сборка автоматически
> подставляет имя репозитория в путь к файлам. Как только вы добавите
> `public/CNAME`, база станет `/` — править `vite.config.ts` не нужно.

> **Про бесплатный тариф.** GitHub Pages на бесплатном плане обычно требует
> публичный репозиторий. Поэтому в проекте нет и не должно быть паролей,
> токенов и персональных данных клиентов — весь контент публичный.

## 6. Свой домен и HTTPS

### Шаг 1. Добавьте CNAME

```bash
# Linux / macOS
cp CNAME.example public/CNAME

# Windows PowerShell
Copy-Item CNAME.example public\CNAME
```

Откройте `public/CNAME` и оставьте в нём **только свой домен**, одной строкой,
без `https://` и без слэша в конце:

```
shinomontazh-shchekino.ru
```

Закоммитьте и отправьте в GitHub. Сборка сама переключит базовый путь на `/`.

### Шаг 2. Настройте DNS у регистратора домена

**Вариант А — корневой домен** (`shinomontazh-shchekino.ru`), четыре A-записи:

| Тип | Имя | Значение |
| --- | --- | --- |
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |

**Вариант Б — поддомен** (`www.shinomontazh-shchekino.ru`), одна CNAME-запись:

| Тип | Имя | Значение |
| --- | --- | --- |
| CNAME | www | ВАШ-ЛОГИН.github.io |

### Шаг 3. Укажите домен в GitHub и включите HTTPS

1. **Settings** → **Pages** → **Custom domain** — впишите домен, нажмите **Save**.
2. Дождитесь успешной проверки DNS. Обычно это от 10 минут до нескольких часов.
3. Поставьте галочку **Enforce HTTPS** — сертификат GitHub выдаёт бесплатно.
4. Через некоторое время включите галочку в настройках репозитория, если
   она стала неактивной: подождите и обновите страницу.

> Файл `public/CNAME.example` в сборку попадает как есть — это просто пример,
> GitHub Pages его игнорирует. Работает только файл с именем `CNAME`.

## 7. Панель управления Pages CMS

Владелец меняет контент через **Pages CMS** — бесплатный сервис, который
редактирует файлы прямо в GitHub-репозитории.

- Интерфейс: <https://app.pagescms.org/>
- Схема полей: файл `.pages.yml` в корне репозитория

### Что доступно владельцу

- Общие настройки: название, описание, город, регион, адрес, телефон, режим работы.
- Логотип и иконка сайта.
- Telegram: имя пользователя и телефон.
- MAX: включение, ссылка на профиль, share-ссылка.
- Яндекс Карты: ссылка на организацию, координаты.
- Рейтинг и количество отзывов.
- Заголовок и описание первого экрана, короткие преимущества.
- SEO: заголовок, описание, превью для мессенджеров.
- Услуги: добавить, изменить, скрыть, удалить, поменять порядок.
- Фотографии: загрузить, подписать, скрыть, удалить, поменять порядок.
- Отзывы: добавить, изменить, скрыть, удалить, указать ссылку на отзыв.

### Что владельцу недоступно

React-компоненты, CSS, HTML-структура, GitHub Actions, `.pages.yml`,
структура проекта, настройки других сайтов и управление участниками.
Это ограничение обеспечивает сам Pages CMS: у участников (collaborators)
нет доступа к конфигурации.

### Как изменения попадают на сайт

```
Владелец правит контент в Pages CMS
        ↓
Pages CMS делает commit в GitHub
        ↓
GitHub Actions пересобирает проект
        ↓
GitHub Pages публикует новую версию
        ↓
Сайт обновляется (1–3 минуты)
```

## 8. Доступ владельца без GitHub

Владельцу **не нужен** аккаунт GitHub. Доступ выдаётся по приглашению на email.

### Что делает разработчик

1. Создаёт репозиторий компании.
2. Устанавливает **Pages CMS GitHub App** на этот репозиторий:
   откройте <https://app.pagescms.org/>, войдите через GitHub,
   нажмите установку приложения и выберите **только этот репозиторий**.
3. Проверяет, что `.pages.yml` заполнен корректно.
4. Приглашает владельца по email в разделе участников Pages CMS.
5. Отправляет владельцу адрес панели и короткую инструкцию.

### Что делает владелец

1. Получает приглашение на email.
2. Открывает <https://app.pagescms.org/>.
3. Входит по приглашению.
4. Видит **только свой** репозиторий.
5. Меняет контент и фотографии.
6. Сохраняет изменения и ждёт пару минут.

### Чего владелец не получает

- GitHub Personal Access Token;
- доступ к другим репозиториям;
- права администратора GitHub;
- доступ к коду и конфигурации;
- возможность редактировать `.pages.yml`;
- возможность приглашать других людей.

> **Если владелец не приглашён**, Pages CMS покажет отказ в доступе. Это
> нормальное поведение, а не ошибка сайта.

## 9. Как менять контент

Все данные лежат в папке `content/`. Ниже — частые задачи.
Через панель управления всё делается в разделе «Контент сайта».

### Заменить данные компании

Файл `content/site.json` или Pages CMS → **Общие настройки**.
Поля: `companyName`, `phone`, `address`, `city`, `region`, `workingHours` и другие.

### Добавить услугу

Pages CMS → **Услуги и цены** → **Добавить услугу**.
Заполните название, описание, цену и единицу измерения.

Для цены «по запросу» оставьте цену пустой, а в поле единицы напишите
«по запросу».

### Изменить цену

Pages CMS → **Услуги и цены** → откройте услугу → поле «Цена, ₽».
Число указывается без знака рубля. Галочка «Показывать от» добавляет «от».

### Добавить отзыв

Pages CMS → **Отзывы** → **Добавить отзыв**.
Заполните имя, оценку, текст и дату. Если нашли отзыв на Яндекс Картах —
вставьте прямую ссылку в поле «Ссылка на отзыв в Яндекс Картах»,
и карточка станет кликабельной.

**Снимите галочку «Демонстрационный отзыв»** для настоящих отзывов.

> Не публикуйте придуманные отзывы от имени реальных людей.

### Добавить ссылку на Яндекс Карты

Pages CMS → **Общие настройки** → «Яндекс Карты — ссылка на организацию».
Это включает кнопки «Построить маршрут», «Открыть адрес на карте»
и «Все отзывы на Яндекс Картах».

### Подключить Telegram

Pages CMS → **Общие настройки** → «Telegram — имя пользователя».
Укажите имя без символа `@`, например `shinomontazh_shchekino`.

Если имя пользователя нет, заполните «Telegram — телефон» в формате
`+79990000000`.

### Подключить MAX

1. Pages CMS → **Общие настройки** → включите «Показывать кнопку MAX».
2. Укажите «MAX — ссылка на профиль».
3. При необходимости заполните «MAX — ссылка для отправки».

Кнопка «Написать в MAX» копирует текст заявки в буфер обмена и открывает
чат. Владельцу нужно вставить текст и отправить его.

## 10. Как работает форма заявки

Форма собирает имя, телефон, услугу и комментарий. Дату и время она не
спрашивает — их клиент согласует с мастером в переписке.

Что происходит при нажатии «Открыть Telegram с заявкой»:

1. Проверяются поля формы.
2. Собирается текст заявки:

   ```
   Новая заявка с сайта

   Имя: {имя}
   Телефон: {телефон}
   Услуга: {услуга}
   Комментарий: {комментарий}
   Компания: {название компании}
   ```

3. Текст кодируется через `encodeURIComponent`.
4. Открывается ссылка `https://t.me/{username}?text={текст}`
   (или переход по номеру, если username не указан).
5. Показывается честное сообщение:

   > Telegram открыт с готовым текстом заявки. Нажмите кнопку отправки
   > в Telegram, чтобы передать заявку владельцу.

**Сайт никогда не пишет «Заявка отправлена»**, пока пользователь не нажал
кнопку отправки в мессенджере. Заявка считается неотправленной до этого
момента.

### Почему нельзя отправить автоматически

Telegram не позволяет статическому сайту писать в чужой личный чат.
Для этого нужен бот с Bot API или серверный backend. И то и другое
запрещено требованиями проекта: сайт должен работать без сервера,
без базы данных и без токенов в клиентском коде.

Поэтому сайт готовит текст и открывает чат, а отправку делает человек.
Это ограничение Telegram, а не недоработка.

### Кнопка «Скопировать заявку»

Копирует подготовленный текст в буфер обмена. Нужна, когда:

- Telegram не установлен;
- нужно отправить заявку в другом мессенджере;
- буфер обмена — единственный доступный способ.

### Защита формы

- обязательная проверка имени и телефона;
- проверка формата номера (10–15 цифр);
- обязательный выбор услуги;
- ограничение длины комментария (500 символов);
- обязательное согласие на обработку данных;
- скрытое honeypot-поле против ботов;
- защита от повторного нажатия;
- понятные сообщения об ошибках;
- автоформатирование телефона при вводе;
- поддержка кириллицы;
- индикация успешного копирования.

## 11. Telegram и MAX

### Telegram — основной канал

- Бот **не используется**.
- Bot API **не используется**.
- Сайт только формирует ссылку и открывает чат.

Ссылка строится в таком порядке:

1. Если указан `telegramUsername` → `https://t.me/{username}?text={текст}`
2. Если username нет, но указан `telegramPhone` → переход к контакту по номеру
3. Если нет ничего → сайт предлагает позвонить и скопировать заявку

### MAX — дополнительный канал

- Кнопка «Написать в MAX» появляется только если включён `maxEnabled`.
- Текст заявки копируется в буфер обмена.
- Открывается профиль MAX (или `maxShareUrl`, если указан).
- Пользователь вставляет текст и отправляет его сам.

Если указана `maxShareUrl`, текст добавляется к ссылке как параметр
`text=` и корректно кодируется.

## 12. Логотип

Логотип **необязателен**.

**Если логотип указан** — показывается изображение с сохранением пропорций
и alt-текстом. Поддерживаются PNG, JPG, WebP и SVG.

**Если логотипа нет** — показывается название компании текстом с аккуратным
знаком из инициалов. Битой картинки и пустого места не будет.

**Если файл логотипа не найден** — картинка скрывается автоматически,
и остаётся текстовый знак.

### Как заменить логотип

1. Положите файл в `public/branding/logo.png`
   (или загрузите через Pages CMS).
2. Pages CMS → **Общие настройки** → «Логотип» → укажите `/branding/logo.png`.
3. Сохраните изменения.

Требования: PNG с прозрачностью или SVG, высота 80–120 px,
горизонтальное расположение предпочтительнее, вес до 200 КБ.

## 13. Фотографии и заглушки

### Две вариации сайта

Сайт умеет работать в двух вариантах. Переключение — поле **`displayMode`**
в `content/site.json` (Pages CMS → **Общие настройки** → «Вариация сайта»):

| Значение | Вариация | Как выглядит |
| --- | --- | --- |
| `photos` | С фотографиями | Большое фото на первом экране, ниже галерея с просмотром по клику |
| `no-photos` | Без фотографий | Вместо снимков — графическая панель с цифрами и блок «Как мы работаем» с этапами |

**Важно:** если выбрано `photos`, но фотографий нет вообще, сайт
автоматически переключится на `no-photos` — пустая галерея не появится.

Для вариации без фотографий заполните в Pages CMS раздел
**«Цифры и факты»** — 4 показателя, которые покажутся на первом экране
и в блоке вместо галереи. Например: «10 лет — опыт мастеров»,
«30 мин — смена комплекта».

Выбор иконки — из готового списка (инструмент, быстро, гарантия, колесо,
галочка, адрес, телефон, часы, звезда, маршрут).

### Какие папки за что отвечают

| Папка | Назначение |
| --- | --- |
| `public/images/company/` | Реальные фотографии компании |
| `public/images/placeholders/` | Заглушки шаблона |
| `public/branding/` | Логотип и превью для мессенджеров |
| `public/uploads/` | Файлы, загруженные через Pages CMS |

### Правило приоритета

Сначала в проекте ищутся **реальные** фотографии компании. Заглушки
используются только тогда, когда настоящих фото нет.

Если вы нашли в проекте реальные фотографии — используйте их и не заменяйте
заглушками.

### Как заменить заглушки на реальные фото

1. Скопируйте фотографии в `public/images/company/`
   (или загрузите через Pages CMS → **Фотографии**).
2. Для каждой записи укажите путь `/images/company/имя-файла.jpg`.
3. Заполните alt-текст и подпись.
4. **Снимите галочку «Это изображение-заглушка».**
5. Сохраните — сайт пересоберётся.

Пока галочка «заглушка» стоит, на фото виден бейдж «Заглушка», а под
галереей выводится пояснение. Заглушки не выдаются за фото конкретной компании.

### Управление галереей

Каждая фотография имеет поля `src`, `alt`, `caption`, `isVisible`,
`sortOrder`, `isPlaceholder`. Через Pages CMS можно загружать, удалять,
скрывать, менять подпись, alt-текст и порядок, а также отмечать файл заглушкой.

В галерее 4–8 изображений, адаптивная сетка, модальное окно с подписями
и навигация клавишами ←/→/Esc. **Первое фото становится главным на первом экране.**

Требования: JPG/PNG/WebP/SVG, около 1600×1200, до 500 КБ на файл.

## 14. Маршрут и Яндекс Карты

Кнопка **«Построить маршрут»** ведёт к конкретному адресу. Приоритет:

1. Если указана `yandexMapsUrl` — открывается она.
2. Иначе, если указаны координаты — используется ссылка с точкой
   `https://yandex.ru/maps/?rtext=~{широта},{долгота}&rtt=auto`.
3. Иначе строится поиск по точному адресу (адрес + город + регион).

Дополнительно есть кнопка **«Открыть адрес на карте»** — она показывает
точку без построения маршрута.

Главная страница Яндекс Карт без адреса не открывается никогда.

На мобильном устройстве ссылка открывается в приложении Яндекс Карт,
если оно установлено; иначе — в браузере. Ссылка всегда открывается
в новой вкладке.

Чтобы задать точную точку, заполните в Pages CMS **«Широта»** и **«Долгота»**,
например `54.005123` и `37.519456`.

## 15. Перенос шаблона на новую компанию

1. Скопируйте репозиторий.
2. Создайте отдельный GitHub-репозиторий для новой компании.
3. Замените `content/site.json`.
4. Замените услуги в `content/services.json`.
5. Замените фотографии в `public/images/company/`.
6. Замените отзывы в `content/reviews.json`.
7. Загрузите логотип или оставьте текстовое название.
8. Укажите Telegram.
9. При необходимости включите и настройте MAX.
10. Укажите точный адрес и координаты.
11. Укажите ссылку на Яндекс Карты.
12. Измените `public/CNAME` на новый домен.
13. Подключите новый домен и включите HTTPS.
14. Установите Pages CMS GitHub App на новый репозиторий.
15. Пригласите владельца по email.
16. Запустите GitHub Actions (push в `main` или **Run workflow**).

React-компоненты переписывать **не нужно** — меняются только данные и фото.

## 17. Если что-то не работает

### Сайт не обновился после правок

1. Откройте вкладку **Actions** и проверьте, что сборка завершилась зелёной галочкой.
2. Если сборка идёт — подождите 1–3 минуты.
3. Обновите страницу с очисткой кэша: **Ctrl + F5** или **Cmd + Shift + R**.
4. Проверьте, что изменения действительно сохранились в репозитории.

### Сборка упала с ошибкой

1. Откройте упавший запуск в **Actions** и посмотрите шаг с ошибкой.
2. Обычно это опечатка в JSON: лишняя запятая, незакрытая кавычка.
   Проверьте `content/*.json` на <https://jsonlint.com/>.
3. Исправьте, закоммитьте — сборка запустится заново.

### Не загружается фотография

- Проверьте путь: он должен начинаться с `/`, например `/images/company/foto.jpg`.
- Убедитесь, что файл действительно лежит в `public/images/company/`.
- Проверьте регистр букв: `Foto.JPG` и `foto.jpg` — разные файлы.
- Допустимые форматы: JPG, PNG, WebP, SVG.

### Не открывается Telegram

- Проверьте, что «Telegram — имя пользователя» заполнено **без** символа `@`.
- Откройте ссылку `https://t.me/ваше_имя` в браузере — она должна работать.
- Если Telegram не установлен, откроется веб-версия.
- В крайнем случае используйте «Скопировать заявку».

### Сайт съехал на телефоне

- Проверьте, нет ли горизонтальной прокрутки.
- Проверьте самый длинный текст в названии услуги или преимущества.
- Сделайте скриншот и опишите модель телефона разработчику.

### Панель управления не открывается

- Проверьте интернет и откройте <https://app.pagescms.org/> заново.
- Убедитесь, что вход выполнен под тем email, на который пришло приглашение.
- Если сервис недоступен — это внешний сервис, повторите позже.
